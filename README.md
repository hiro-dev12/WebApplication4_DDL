# WebApplication4_DDL - Database Definition Project

このリポジトリは、勤怠管理ツール（WebApplication4）で使用する  
データベース定義（DDL）を管理する専用プロジェクトです。

アプリケーションコードと DB スキーマを分離し、  
保守性と拡張性を高めることを目的としています。

---

## 設計背景

勤怠表や反映ツールを社内で一人で担当している経験があるため、  
実務をイメージしやすく、自然と業務に近い構成になっています。  
ただし、社内で使用している勤怠表や反映ツールの仕様は社内秘のため、  
本リポジトリには一切含めていません。

公開している内容はすべて学習目的で自作したものです。

---

## 管理対象テーブル

### attendance（勤怠実績）
ユーザの勤怠情報を保持するテーブル。

### cholidays（会社休日）
会社が定める年間休日を保持するテーブル。

### holidays（祝日）
外部公開されている祝日データを取り込む前提で設計したテーブル。

### users（ユーザ情報）
ユーザ名、権限などを管理するテーブル。  
パスワードはハッシュ化前提で設計しています。
