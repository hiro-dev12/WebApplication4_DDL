# WebApplication4_DD - Database Definition Project

このリポジトリは、勤怠管理ツール（WebApplication4）で使用する  
データベース定義（DDL）を管理する専用プロジェクトです。

アプリケーションコードと DB スキーマを分離し、  
保守性と拡張性を高めることを目的としています。

---

## 管理対象テーブル

### attendance（勤怠実績）
ユーザの勤怠情報を保持するテーブル。  
日付、勤怠区分、登録日時などを管理します。

### cholidays（会社休日）
会社が定める年間休日を保持するテーブル。

### holidays（祝日）
外部公開されている祝日データを取り込む前提で設計したテーブル。

### users（ユーザ情報）
ユーザ名、権限などを管理するテーブル。  
パスワードはハッシュ化前提で設計しています。
